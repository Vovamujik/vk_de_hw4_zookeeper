# ДЗ 4: отказоустойчивость средствами Apache ZooKeeper

Ансамбль из трёх серверов ZooKeeper 3.9.6 на одной машине и две копии координатора расчёта пар навыков из ДЗ 3 с выбором лидера, чекпоинтом и защитой по эпохе.

**Отчёт:** [REPORT.md](REPORT.md) (то же в PDF — [report/hw4_zookeeper_report.pdf](report/hw4_zookeeper_report.pdf))

## Результаты

- Три сервера: лидер и два последователя. Без одного сервера ансамбль работает, без двух нет. Эфемерный узел исчез через 29 с после закрытия окна с zkCli (тайм-аут сессии 30 с).
- Без защиты две записи результата, указатель версии 2. С `FENCING=1` запись старого лидера отклонена с `BadVersionError`, указатель версии 1 от запасного.
- Результат в обоих запусках совпал с ДЗ 3 байт в байт: 7 124 пары, сумма 39 256. Смена лидера заняла 10,89 и 11,20 с при тайм-ауте сессии 10 с.

## Где что

- `zookeeper/zk{1,2,3}/conf/zoo.cfg`, `zookeeper/zk{1,2,3}/data/myid`: конфигурации серверов
- `coordinator.py`: координатор, `scripts/failover.py`: сценарий паузы лидера
- `logs/`: журналы координаторов и серверов, `outputs/`: выводы команд, `report/img/`: снимки экрана
- `hw/`: код расчёта из ДЗ 3 без изменений
