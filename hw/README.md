# hw/ — код расчёта из ДЗ 3 без изменений

Файлы скопированы из репозитория ДЗ 3 (`de_hw3_mapreduce_duckdb/hw`) как есть: правила варианта Go
(`normalize.py`), чтение сплитов CSV из RustFS Range-запросами и map-таск (`mapreduce.py`),
задача подсчёта навыков, пар и троек (`jobs.py`), клиент S3 (`s3.py`), настройки (`settings.py`).
Координатор ДЗ 4 (`coordinator.py`) вызывает отсюда `mapreduce.run_map_task` для каждого сплита,
поэтому расчёт тот же, что в ДЗ 3. Совпадение с ДЗ 3 проверено, вывод — `outputs/hw3_copy_check.txt`.
